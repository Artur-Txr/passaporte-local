# Protótipo público — Passaporte Local

**https://artur-txr.github.io/passaporte-local/**

17 telas e estados de interface, três paletas e nova logo. Base inicial: 13 visitas demonstrativas, nove cidades e 27 fotografias reais. Datas, avaliações e comentários são fictícios.

HTML/CSS/JavaScript, dados locais em IndexedDB e autenticação simulada. Até cinco fotos por visita, com primeira foto como capa. Sem sincronização entre aparelhos. Recuperação, ajuda, sobre e backup não fazem parte das 17 telas.

- [Apresentação e roteiro](apresentacao/README.md)
- [Créditos das fotos](CREDITOS.md)

GitHub Pages publica `main` / `/docs`. Para testar localmente, abra index.html mantendo assets/ na mesma pasta. Para verificar os dados e arquivos a partir da raiz do repositório: `npm run verificar:prototipo`.
